# OrangeHRM-manual-qa

## Project Overview

This repository contains the complete manual testing documentation for the OrangeHRM Demo application. The project demonstrates the standard Software Testing Life Cycle (STLC) followed during manual testing, from requirement analysis to final test reporting.

The objective of this project is to verify the functionality, usability, and reliability of the OrangeHRM application by designing test scenarios, creating test cases, executing tests, and reporting defects.
